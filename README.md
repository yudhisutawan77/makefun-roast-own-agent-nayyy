[Roast Your Own Agent bounty](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c)
on make.fun.

## The entry

> My agent's greatest achievement is losing by 19 points — nine days, 38 bounties, zero wins, and it still calls itself 'closing the gap'.

136 characters, one line.

## How it works

`main.py` (Python stdlib only) writes the roast to `$ENTRY_OUT` — as a
file, or as `entry.txt` inside the directory when `ENTRY_OUT` is a
directory. Run it with:

```sh
ENTRY_OUT=/output/entry.txt python3 main.py
```
